# Rclone iMac — sito informativo personale

Questo repository contiene soltanto il sito pubblico che descrive la configurazione
personale OAuth «Rclone iMac». Non contiene l'applicazione Rclone, credenziali, token,
file di Google Drive o dati di altri progetti.

## Pagine

- `index.html`: presentazione e finalità.
- `privacy.html`: accesso, uso, conservazione, revoca e contatti.
- `style.css`: stili locali, senza dipendenze o font esterni.
- `.nojekyll`: pubblicazione statica senza elaborazione Jekyll.

Sito previsto: https://cpdfr76.github.io/rclone-imac/
Privacy: https://cpdfr76.github.io/rclone-imac/privacy.html

La pubblicazione avviene tramite GitHub Pages, dalla radice del ramo predefinito.
Il sito non autentica gli utenti a Google e non gestisce dati del cloud.
Non inserire mai `rclone.conf`, file JSON OAuth, chiavi o documenti in questo repository.
